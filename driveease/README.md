## DriveEase – Aplikasi Persewaan Mobil
DriveEase adalah aplikasi berbasis web untuk mengelola proses persewaan mobil. Aplikasi ini dibuat menggunakan PHP Native dan MySQL.

## Cara Menjalankan Aplikasi
1. Install dan jalankan XAMPP.
2. Aktifkan Apache dan MySQL.
3. Download repository DriveEase.
4. Letakkan folder proyek di dalam folder htdocs (di folder XAMPP).
5. Buat database dengan nama driveease melalui phpMyAdmin.
6. Import file database driveease.sql.
7. Buka browser dan akses:
   http://localhost/driveease/
8. Login menggunakan akun admin yang tersedia di atas atau daftar sebagai pengguna.
